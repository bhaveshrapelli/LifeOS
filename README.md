# 🚀 LifeOS

LifeOS is a modern productivity and life management platform designed to help users organize tasks, track goals, manage routines, and improve daily efficiency through a clean and intelligent dashboard experience.

---

## 🌟 Features

- 🔐 User Authentication System
- 📋 Task & To-Do Management
- 🎯 Goal Tracking
- 📅 Daily Planner
- 📊 Productivity Dashboard
- 🌙 Responsive Modern UI
- ⚡ Fast & Lightweight
- 📱 Mobile-Friendly Design

---

## 🚀 Installation

### Clone the Repository

```bash
git clone https://github.com/bhaveshrapelli/LifeOS.git
```

### Navigate to Project Directory

```bash
cd LifeOS
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Virtual Environment

#### Windows

```bash
venv\Scripts\activate
```

#### Mac/Linux

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
python app.py
```
